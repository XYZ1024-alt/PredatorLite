PredatorLite is a framework-dependent ReadyToRun application for Windows 11 24H2 (build 26100+) x64.

Before launching PredatorLite, install:

- Microsoft .NET 10 Runtime for Windows x64
- Microsoft Windows App Runtime 2.3 for Windows x64

The installer requires an administrator account to install PredatorLite into a protected Program Files directory. This prevents a non-administrator from substituting the elevated helper that Windows launches with administrator rights. The main application runs without administrator privileges; Windows requests elevation only when you explicitly ask PredatorLite to manage a conflicting service.
